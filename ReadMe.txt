To run the codes, please install jupyter notebook or vscode on your system.
The order to run the codes is the following:
1. Run "AI_Assignment_maze_generator.ipynb" where you need to mention the grid size which you need.
2. Run "AI_Assignment_bfs.ipynb" where you mention the grid size that you generated for the BFS algorithm to run on it.
3. Run "AI_Assignment_dfs.ipynb" where you mention the grid size that you generated for the DFS algorithm to run on it.
4. Run "AI_Assignment_astar.ipynb" where you mention the grid size that you generated for the Astar algorithm to run on it.
5. Run "AI_Assignment_mdp_value_iteration.ipynb" where you mention the grid size that you generated for the MDP Value Iteration algorithm to run on it.
6. Run "AI_Assignment_mdp_policy_iteration.ipynb" where you mention the grid size that you generated for the MDP Policy Iteration algorithm to run on it.

All the results are stored in "results.csv".
All the mazes are stored in Mazes directory.
All the paths generated are stored in Paths directory.
